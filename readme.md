# SumatraPDF (DN-fork) - Automated Build

このリポジトリは、登 大遊 氏による **SumatraPDF の独自改良パッチ適用版 (DN-fork)** を GitHub Actions で自動ビルドし、実行バイナリを提供するものです。

## 🚀 特徴 (DN-fork Patch2)
元の SumatraPDF に、以下の高度なパッチが適用されています。
- **キー操作の改善:** アクセラレータキー（ショートカット）の挙動の修正・最適化。
- **軽量・高速:** SumatraPDF 本来の軽さを維持しつつ、特定の使い勝手を向上。

## 📦 ダウンロード
右側の **[Releases]** セクションから、最新の `SumatraPDF.exe` をダウンロードできます。
> ※ インストール不要のポータブル版として動作します。

## 🛠 ビルドについて
本リポジトリでは GitHub Actions を利用し、クリーンな環境で MSVC (Visual Studio 2022) を用いてビルドを行っています。
